# IKORC · Company Website

Multi-page refinery introduction website built with HTML, Bootstrap and JavaScript, with operating-unit and gallery pages.

[Deployment link](https://ikorc-new.vercel.app) · [Source](https://github.com/Erfan-Ebrahimi/IKORC1)

## Stack

HTML · CSS · Bootstrap · JavaScript · AOS

## What's inside

- Company introduction and about page
- Operating-unit pages
- Gallery and contact presentation

## Local setup

Serve the repository root with a local static web server, then open `index.html`. No npm build step is configured in this repository. Keep the asset folders next to the HTML files.

## Project layout

- `index.html` — company overview
- `about.html` — about page
- `unit1.html` through `unit6.html` — operating-unit pages
- `assets/` — styles, scripts, images and bundled vendor files

See `Readme.txt` for the original bundled template information. Keep existing third-party notices when reusing the assets. This repository contains the website interface.
